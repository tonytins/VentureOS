# VentureOS 0.3

VentureOS 0.3 gives VentureOS a desktop, with apps of its own and a look you can change. The last build is
0.3.18, tagged `v0.3.18`. The [changelog](../../changelog.md) lists each build's changes, from 0.3.0 to 0.3.18.

## Before you start

- VentureOS runs from memory. Files you create or change, your apps, and your choice of look last until you
  reboot or shut down.
- It's built and run under QEMU on x64. It builds for ARM64 too, but hasn't been booted there.
- 0.3 is the only supported release. Until 1.0, only the latest release is.

## Open the desktop

Boot VentureOS, then type `desktop` at the prompt. To come back to the shell, choose VentureOS ▸ Return to Shell
(Ctrl+Shift+Q).

The desktop has a menu bar along the top, which shows the menus of the app in front, and a dock along the bottom,
with the system's apps first and yours after a divider.

## Work with windows

- Drag a window by its title bar, and click a window to bring it to the front.
- The red button closes a window, and the orange one sends it to the dock. Click its tile in the dock to bring it
  back.
- Drag the dots in the bottom-right corner of Files and TextEdit to resize them.
- Rest the pointer on a control for half a second to see what it does, where the app says, such as the color
  swatches in Settings.
- Closing an app's last window quits it. Files is the exception: it keeps running, and its menus show when no
  other app is in front.

## Use the apps

| App | What it's for |
|---|---|
| Files | Browse folders. Double-click a folder to open it, an app to start it, or a text file to edit it. Quick Look (Ctrl+Y) shows any other file without opening it. Click the address in the title bar, or press Ctrl+L, to type a path. |
| Settings | Choose light or dark, and an accent color: one of eight swatches, or your own `#RRGGBB`. |
| System Monitor | The version, how long VentureOS has been up, memory in use, and the network, updated every second. |
| Terminal | The shell in a window. Each window has its own current folder; type `exit` to close it. |
| TextEdit | Open, edit, and save text files. Type a path in its title bar and press Enter to open one. |
| Calculator | Add, subtract, multiply, and divide. |
| Notes | Keep short notes. While Notes is open, `note` adds one from the shell too. |

Your own apps live in `/mnt/user/apps`, where you can change or delete them. The system's live in
`/mnt/system/apps`, which nothing can change.

## Change the look

Use Settings, or type `appearance` in the shell or Terminal:

```sh
appearance dark
appearance light --accent "#E8922A"
```

Every window, the menu bar, the dock, and the sky change at once. VentureOS saves your choice in
`/mnt/user/settings/appearance.xml` and restores it when it starts, until you reboot. To start every boot with a
different look, change `rootfs/user/settings/appearance.xml` before building.

If saving fails, the look still changes, and Settings or `appearance` tells you why it couldn't be saved.

## Write apps

An app is a folder ending in `.app`, with a Lua script and an interface written in UIScript (`.uix`).
[Writing apps](../writing-apps.md) walks through one from start to finish. 0.3 adds these to what an app can use:

- Windows with a title bar of their own buttons, an editable title, and a sidebar (`<Sidebar>`, with
  `requires="sidebar"`).
- Resizable windows (`resizable="true"`), whose controls follow the edges their edge offsets name.
- Styles that follow the desktop's look, such as `textColor="secondaryText"` or `fontSize="title"`, with dark
  twins for exact colors. See [UIScript styles](../uiscript-styles.md).
- Hover text, from a `<String>` in a CST table beside the app's `.uix`.
- Multi-line text (`<TextArea>`), code that runs on a schedule (`window:every`), and handing a file to another app
  (`venture.ui.launch`).

## Known limits

- Undo and Redo aren't there yet, and nor are Cut, Copy, and Paste.
- Terminal's window can't be resized.
- Hover text reads only keys written on the same line as their text in a CST table. VentureOS tells the app about
  anything else in the table, and skips it.
