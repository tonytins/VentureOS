# VentureOS 0.4, Pere Marquette

VentureOS 0.4 gives every app the same menus and the same way of editing text, and lets VentureOS reach the
network. The last build is 0.4.500, tagged `v0.4.500`. The [changelog](../../changelog.md) lists each build's
changes, from 0.4.100 to 0.4.500.

## Before you start

- VentureOS runs from memory. Files you create or change, your apps, and your choice of look last until you
  reboot or shut down.
- It's built and run under QEMU on x64. It builds for ARM64 too, but hasn't been booted there.
- 0.4 is the only supported release. Until 1.0, only the latest release is.

## Use the menus every app has

Every app has File, Edit, and Help in the menu bar, whatever's open, with no work from the app. Items that can't
do anything at the moment are dimmed.

| Menu | Items |
|---|---|
| File | Close Window (Ctrl+W), after the app's own File items |
| Edit | Undo (Ctrl+Z), Redo (Ctrl+Shift+Z), Cut (Ctrl+X), Copy (Ctrl+C), Paste (Ctrl+V), and Select All (Ctrl+A) |
| Help | About the app, with its name, version, and what it's for |

An app's own menus sit between Edit and Help. Quit stays in the app's menu, beside the VentureOS menu.

## Edit text

These work the same in every text field, text area, and window address, such as Files' path:

- **Select** by dragging across text, by holding Shift with the arrow keys, Home, or End, or with Ctrl+A for all
  of it. Typing replaces what's selected, and Backspace or Delete removes it.
- **Click** in a field to put the caret where you click.
- **Edit an address:** clicking it, or pressing Ctrl+L in Files, selects the whole path, so you can type a new one.
  Press End or an arrow key to change it instead.
- **Copy and paste** between any apps. The clipboard lasts until you leave the desktop. Pasting into a one-line
  field turns line breaks into spaces.
- **Undo and Redo** step back a word of typing at a time, or a whole paste or cut. Each field keeps its own
  history, up to 100 steps.

Password fields can't be cut or copied.

## Reach the network

Under QEMU's user networking, VentureOS gets an address and a DNS server from the network when it starts.

```sh
net                      # the adapter, its address, and its DNS server
resolve example.com      # the address a host name has
ping 10.0.2.2            # four echo requests, and how long each reply took
ping -c 10 example.com   # ten, to a host name
```

Scripts can do the same with `venture.resolve` and `venture.ping`, with `network` in their `-- Needs:` line.

## Write apps

[Writing apps](../writing-apps.md) walks through one from start to finish. 0.4 adds these to what an app gets or
can use:

- The standard menus. Give a `<Menu>` the `role` `file`, `edit`, `view`, or `help`, or the title `File`, and its
  items join that menu; leave out your own Close Window and copy and paste. An item of yours with the same
  shortcut as a standard one is used instead of it.
- `description` in `Info.xml`, which About shows.
- Selection, the clipboard, and Undo and Redo in every text field and area. Setting a field's text yourself starts
  its undo history over.

## Known limits

- Pinging an address on the local network that nothing answers takes several seconds before it says so.
- Ping times read in steps of 10 ms, so a fast reply shows as 0 ms.
- Undo covers text only, not an app's own actions, such as deleting a note.
- Terminal's output can't be selected or copied, and Terminal's window can't be resized.
