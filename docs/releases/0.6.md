# VentureOS 0.6, Izumo

VentureOS 0.6 is Roundhouse, VentureOS's IDE: a desktop app for Linux, Windows, and macOS that opens an app's
bundle, edits its files, designs its windows on a canvas drawn by VentureOS's own code, and runs it in VentureOS's
desktop without QEMU. The last build is 0.6.505, tagged `v0.6.505`. The [changelog](../../changelog.md) lists each
build's changes, from 0.6.100 to 0.6.505.

## Before you start

- Roundhouse runs on your computer, not on VentureOS. A version that runs on VentureOS itself comes later.
- Roundhouse comes as packages that need nothing installed: an AppImage and a `.tar.gz` for Linux, a zip for Windows,
  and `Roundhouse.app` for macOS. Build them with the scripts in [`packaging/`](../../packaging/README.md), or run it
  from the repository with `dotnet run --project src/Venture.Roundhouse`.
- VentureOS itself still runs from memory, under QEMU on x64. It builds for ARM64 too, but hasn't been booted there.
- 0.6 is the only supported release. Until 1.0, only the latest release is.

## Open an app

- **File ▸ Open Bundle…** (Ctrl+Shift+O) opens an app's folder, or open any file in it. Its files are listed over the
  outline; choosing one shows it.
- **Interfaces** (`.uix`) open in the designer. **Lua** opens in an editor with highlighting, other text as plain text,
  and pictures as they are.
- **`Info.xml`** shows a form above its text: name, identifier, version, description, the scopes an app needs, and its
  main script and icon, with the icon shown as the dock shows it. A value VentureOS wouldn't take says why under its
  field.
- **File ▸ New App** (Ctrl+N) makes a window app to start from, with a button that counts its presses.
- Edits stay while you move between files. Files with unsaved edits are marked ●; Save (Ctrl+S) saves the file shown,
  and Save All (Ctrl+Shift+S) every one. Leaving a bundle with unsaved edits asks first.

## Design a window

- The canvas shows the window as VentureOS draws it, in light or dark and any accent, at 100% or 200%. The text below
  it follows every change, and changes to the text redraw the canvas.
- **Select** a control on the canvas or in the outline, **drag** to move it, and drag its handles to resize it. The
  arrow keys nudge it. The title bar, toolbar items, the title field, and the sidebar can be selected and sized too.
- **The inspector** shows every attribute the selection can have, grouped. A value VentureOS wouldn't accept is
  explained and changes nothing.
- **Add ▾** (and Insert) adds controls, toolbar items, menus, menu items, and sidebars. Duplicate, Delete, Forward, and
  Backward are under Edit and Arrange.
- A document's **menus** show above its window, in VentureOS's menu bar, as Xcode shows an app's.
- **Saving** writes back only what changed: comments, spacing, attribute order, and line endings stay as written, and
  a document you didn't change is saved exactly as it was opened.

## Run

- **Run** (Ctrl+R) runs VentureOS's desktop in a 1024x768 window, from the same code, with the app open as it's
  being edited, saved or not.
- Each run starts from a fresh copy of VentureOS's files, and nothing it changes outlasts it. Scripts in a run can't
  reach files outside that copy.
- Restart (Ctrl+Shift+R) starts a fresh run; Stop (Ctrl+.) ends it.

## The rest of Roundhouse

- Menus in your desktop's global menu bar on KDE and macOS, or from ☰ elsewhere.
- A title bar laid out like a VentureOS window's, which replaces the window manager's on Linux.
- A **Log** tab beside Text shows what Roundhouse did and what apps printed in Run. The same log is kept in a file a
  day, for a week, under your local application data, in `Roundhouse/logs`.
- `Roundhouse --render document.uix picture.png` draws a `.uix` into a PNG, in light or `--dark` and with any
  `--accent`.

## For app writers

- Apps open windows without listing `ui` in `needs`. An app that still lists it works as before.
- Any script can show a message with `venture.ui.alert(message, title)`, Quick Look a file with
  `venture.ui.preview(path)`, and open an app with `venture.ui.launch(app, file)`.

## Known limits

- Roundhouse's icon is a placeholder, and its toolbar uses text and symbols until its art arrives.
- Run has no QEMU underneath: it runs VentureOS's desktop code, not its kernel, so drivers, networking, and the shell's
  built-in commands aren't there.
- Apps made or edited in Roundhouse can't yet be put on a running VentureOS; they ship by being added to `rootfs/`
  before building.
- The bundle's file list has roomy rows on Linux, from Avalonia's theme.
