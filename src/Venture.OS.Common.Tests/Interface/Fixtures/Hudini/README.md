# Hudini's example documents

These UIScript documents are copied unchanged from
[Hudini](https://github.com/tonytins/Hudini) (`Sources/hudini-demo/Resources/`,
commit `908728d`), which defines the format. VentureOS's reader is tested
against them so the two readers agree. They're covered by Hudini's BSD 3-Clause
license, in [LICENSE](./LICENSE), not by VentureOS's Unlicense.

Refresh them by copying the files again when Hudini's examples change.
