# Hudini's example documents

These UIScript documents are copied unchanged from
[Hudini](https://github.com/tonytins/Hudini) (`Demo/Sources/hudini-demo/Resources/`
and its `city/` folder, commit `c7e6037`), which defines the format. VentureOS's reader is tested
against them so the two readers agree. They're covered by Hudini's BSD 3-Clause
license, in [LICENSE](./LICENSE), not by VentureOS's Unlicense.

Refresh them by copying the `.uix` files again when Hudini's examples change; the
tests read every `.uix` here, so a new one is tested without a code change.
